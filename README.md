# 🏦 Bank Term Deposit Prediction

## 📌 Project Overview

This project aims to predict whether a bank customer will subscribe to a term deposit based on their demographic information, financial details, and previous marketing campaign interactions.

The goal is to help banks identify potential customers and improve the effectiveness of their marketing campaigns using Machine Learning.

## 🎯 Problem Statement

Bank marketing campaigns involve contacting a large number of customers, but not every customer is likely to subscribe to a term deposit.

This project develops a classification model to predict customer subscription behavior and support data-driven marketing decisions.

## 📊 Dataset

The project uses a bank marketing dataset containing customer information and campaign-related attributes.

**Target Variable:**
- `y` – Indicates whether the customer subscribed to a term deposit (`yes` or `no`).

The models are evaluated using:

- Accuracy

## 🚀 Key Objectives
